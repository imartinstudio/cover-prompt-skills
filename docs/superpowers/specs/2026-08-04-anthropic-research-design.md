# Anthropic Research 风格封面技能设计

## 目标

新增一个可独立安装、可独立调用的基础封面技能 `cover-anthropic-research`，将 X 帖子
[Adrian Punk 的参考帖子](https://x.com/AdrianPunk115/status/2083411308855111928?s=20)
中展示的“Anthropic Research / 研究编辑极简”视觉语言抽象为可复用提示词规则。

## 范围

- 新增一个基础 `cover-X` 技能，支持仓库统一的 `template | prompt | all` 输出契约，默认输出 `template`。
- 新增 Claude/Codex plugin manifest、历史来源说明，并纳入 marketplace、CoverTips 和安装索引。
- 不新增 `cover-anthropic-research-with-docs`。当前来源只证明单张封面风格，没有足够证据定义文章正文图的章节绑定和视觉任务。
- 不修改现有风格规则，不新增外部图片资产，不调用实际生图服务。

## 视觉契约

1. 背景采用五套固定方案之一：陶土橙 `#D97757`、深黑 `#1A1A1A`、暖灰 `#D8D5CF`、鼠尾草绿 `#B8C9B8`、雾霾蓝 `#8FA9C7`；整张图保持大面积纯色，不随机换色。
2. 主标题是绝对视觉中心，优先使用具有明显粗细变化的高级衬线字体；辅助文字才使用简洁无衬线字体，等宽字体只少量使用。
3. 视觉主体使用黑色手绘线稿和抽象结构做主题隐喻，不直接绘制主题物品；可使用浅色纸张形状承载线稿。
4. 只保留一个主标题，副标题可留空；不添加栏目标签、页码、日期、Logo、品牌署名或无意义英文说明。
5. 装饰色块控制为 2–4 个、总面积不超过 5%，采用不规则有机形、手绘圆形、小矩形或纸张形状，不能排列成 UI 控件。
6. 明确排除营销海报、科技发布会、赛博朋克、渐变、霓虹、蓝色光效、3D、复杂信息图、密集文字和官方品牌标志。

## 输出设计

模板字段覆盖主题、标题、副标题、核心表达、画幅比例、用途、背景方案、视觉隐喻、字体和禁用元素；提示词模式输出一条可直接交给图像模型的完整提示词，不输出分析过程或多稿。默认比例按用途推断，X/文章宽幅优先 `5:2`，用户指定比例时视为硬约束。

## 验证

- 先让库存测试在新增技能缺失时失败，再创建插件。
- 运行 `python3 scripts/skill_registry.py check`，确认 manifests、CoverTips、marketplace、安装索引和生成文件一致。
- 运行 `python3 -m unittest discover -s tests -v`，并检查新增 `SKILL.md` 的 frontmatter、触发描述和视觉规则。
