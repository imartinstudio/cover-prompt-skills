【版式设计】

【字体】

标题：高级衬线字体。

【视觉主体】

根据主题生成一个抽象隐喻插画。
不要直接画主题物品。

使用：

抽象结构；
概念符号。

例如：
AI主题：不要画机器人。可以表现：人类轮廓 + 智能节点 + 思考路径。
网页主题：不要画普通电脑。可以表现：数字空间结构；网页模块像建筑一样生成。
知识主题：不要画书堆。可以表现：信息节点汇聚成知识结构。
