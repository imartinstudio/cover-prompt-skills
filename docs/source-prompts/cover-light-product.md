### 一句话核心

**AI 正在工作，而不是人在办公。**

画面展现的是 Agent Workspace——多个 AI Agent 正在同时协同完成复杂任务。这是未来的工作方式，不是过去的办公场景。

### 叙事策略

画面应该让人产生以下联想：

- "这是下一代工作方式"
- "AI Agent 在帮我做事"
- "复杂任务被自动编排和执行"
- "我只需要定义目标，Agent 负责执行"
- "这是一个智能系统，不是一个工具"

### 可以展现的概念场景

- Agent Workspace：多个 Agent 节点并行工作
- Multi-Agent Collaboration：Agent 之间传递信息、协同决策
- Browser Automation：Agent 在浏览器中自动操作
- Task System：任务被分解、分配、执行、验证
- Workflow Graph：工作流节点与连线，展现编排逻辑
- Knowledge Graph：知识之间的关联网络
- Context Network：上下文在 Agent 之间流动
- Research Pipeline：从搜索到分析到输出的完整链路
- AI Coding Workflow：代码生成、审查、测试、部署的自动化流程
- Dashboard：实时任务状态与数据可视化
- Memory System：持久化记忆与检索
- Knowledge Base：结构化知识存储
- Design Workspace：AI 辅助设计工作区
- Automation Flow：自动化流程可视化
- Execution Status：实时执行状态面板

### 元素使用原则

1. 元素丰富但不杂乱——每个元素都有自己的位置和功能

3. 前景主体 + 中景信息层 + 背景氛围层的三层结构
4. 元素之间必须有视觉关系（连线、对齐、分组），不能是孤立的
5. 优先展现"系统正在运行"的状态，而非静态空界面

### 用色规则

1. 整体低饱和——不刺眼，不荧光，不糖果色
2. Claude 暖色与 Codex 冷色按 4:6 或 6:4 比例搭配，形成冷暖对话
3. 彩色仅用于 10-20% 的画面面积（强调、节点、连线）
4. 80-90% 画面保持中性色（白、灰、奶油）
5. 一个画面内暖色和冷色必须同时存在，形成双品牌融合感
6. 可以有极少量渐变（Claude 暖 → Codex 冷），用于背景或关键元素

### 三层视觉结构

整个画面清晰分为三层：

- **第一层：主体视觉区（60-70%面积）**
  核心视觉叙事所在——Agent 工作区、Dashboard、工作流图等
  这是画面第一眼看到的内容

- **第二层：标题文字区（15-25%面积）**
  主标题 + 副标题
  排版精良，与主体视觉形成对话关系

- **第三层：信息标签区（5-10%面积）**
  平台标识、分类标签、日期、小字说明
  强化专业编辑感

### 构图模式（自动选择最合适的）

**模式A：左文右图**
- 左侧大面积标题 + 副标题
- 右侧 Agent 工作区视觉
- 适合 X 封面、LinkedIn 封面等横长画幅

**模式B：上图下文**
- 上方大面积 Agent 工作区
- 下方标题系统
- 适合公众号首图、B 站封面

**模式C：中央聚焦**
- 中央大面积 Agent Dashboard
- 标题叠加或置于底部
- 适合小红书、咸鱼等竖幅

**模式D：全幅工作区**
- 整个画面就是一个精致的 Agent Workspace
- 标题作为 UI 的一部分嵌入（如 Dashboard 标题栏）
- 适合需要强烈沉浸感的场景

### 构图要求

1. 大量留白——画面 30-40% 应为留白区域
2. 信息密度在主体区域高，在留白区域为零
3. 具有杂志排版感——文字大小对比强烈（大字很大，小字很小）
4. 具有产品发布会视觉质感——像 Keynote 幻灯片，不是 Banner 广告
5. 具有 SaaS 官网 Hero 质感——像 landing page 的第一屏

【文字排版规则】
━━━━━━━━━━━━━━━━━━━━

### 标题策略

1. 主标题必须醒目，使用大号无衬线字体
2. 如果标题较长（超过 8 个中文字），考虑提炼关键词做大字，完整标题做副标题
3. 标题与视觉主体之间必须有呼吸空间
4. 标题可以叠在视觉主体上，但必须保证可读性

### 字体气质

- 中文：现代几何黑体 / 无衬线，干净利落
- 英文：SF Pro / Inter / Untitled Sans 风格，现代科技感
- 数字/数据：等宽字体感，增强工具属性

### 辅助文字

- 副标题使用小号字体，与主标题形成 3:1 到 5:1 的大小对比
- 可加入极小的分类标签：AGENT · WORKFLOW · AUTOMATION · AI NATIVE
- 可加入类似产品 UI 的状态文字："3 agents running"、"Task completed"

### 禁止出现的元素

不要表现传统办公场景的任何元素：

- 咖啡杯、笔记本、铅笔、尺子
- 台灯、植物、书桌摆件
- 人手、打字的手、握笔的手
- 办公室、工位、会议室

### 禁止出现的俗套科技元素

- 芯片、电路板、PCB 走线
- 机器人、机械臂
- 发光大脑、神经网络球体
- 赛博朋克城市、霓虹雨夜
- 宇宙星空、地球、粒子宇宙
- 锁、盾牌（安全图标）
- 握手（合作图标）
- 灯泡（创意图标）

### 禁止的设计风格

- 廉价 AI 海报风（Midjourney 默认审美）
- 普通商业插画感
- 电商封面感
- 信息图模板感
- 过度 3D 炫技
- 花哨边框和装饰
- 荧光渐变色
- 暗黑模式（本风格以浅色为主）

### 禁止的设计错误

- 文字与背景对比度不足
- 元素漂浮无关联
- 画面太满，没有呼吸感
- 彩色面积超过 30%
- 只有暖色或只有冷色（必须冷暖共存）
- 标题不可读或变形过度
