4. 采用“字中有画、画中有意、意中有信息”的方式进行构图：让核心字既是文字、也是图像容器、也是主题隐喻。
5. 整体不是简单插画，也不是普通排版，而是“汉字结构 + 插画叠底 + 信息设计 + 东方留白美学”的综合作品。

【视觉风格要求】
- 整体风格：高级、克制、典雅、专业、安静、耐看、具有东方哲思与文化气息
- 背景材质：宣纸、旧纸、细腻纸张肌理、淡淡水痕、朦胧花影、古籍质感、轻微岁月痕迹
- 色彩系统：低饱和配色，以米白、茶褐、灰绿、淡墨、浅赭、暖灰、沉静木色为主，必要时可根据主题加入少量点睛色，但必须克制
- 气质方向：宋代美学、文人气、书卷气、东方展览视觉、国风编辑设计、高级出版物气质
- 画面质感：细腻、雅致、具有艺术微喷与展陈海报质感，不廉价、不俗艳、不网红模板化

【主视觉结构】
- 以“核心字 / 核心词”的汉字结构作为画面主体，尺寸显著放大，占据海报核心位置
- 核心字不是普通排字，而是采用“插叠底 / 蒙版嵌入 / 画中成字”的方式处理
- 在核心字内部嵌入与主题相关的视觉内容，形成“剪影式内容容器”
- 内容可包含：人物、器物、山水、场景、知识符号、文化意象、结构图示、情境片段、主题相关的微型叙事画面
- 根据主题属性自动调整嵌入内容：

  - 若主题偏知识 / 学术 / 科普 / 理论：以具有东方审美重构后的知识图示、象征性器物、结构化场景、逻辑符号为主
  - 若主题偏邀请函 / 活动宣传：以活动氛围、主题意象、人与场景互动为主

- 保证“核心字”与内部内容之间的关系清晰自然，既要有图像叙事，又要保持整体识别性

【插画与图像语言】
- 图像风格优先采用：中国古典工笔画 + 水墨淡彩 + 古画拼贴融合
- 可带有卷轴、古画残片、器物纹理、庭院、山石、书案、竹林、云气、灯影、纸本设色等元素
- 画面中的人物、器物、景物要小而精，富有细节，具有“可细看”的收藏价值
- 插画边缘可有轻微晕染、纸本磨损感、叠底印刷感，使其像印在纸中，而非生硬贴图
- 如果主题更现代，可在保留东方底蕴的基础上，融合现代信息图语言，但整体仍要高级、克制、文化感强

【版式与信息层级】
请参考高端展览海报、文化邀请函、艺术出版物封面、编辑设计海报的版式逻辑，确保结构清晰、信息高级、层次严谨。

必须具备以下层级：
1. 主标题：突出主题，建议放在右侧竖排或核心区附近，字体气质古雅、修长、稳定
2. 副标题 / 英文辅助标题：可用于补充主题气质，采用细衬线字体，低调排布
3. 基础信息区：如时间、地点、主办方、活动主题、对象、栏目名等，排版整齐克制
4. 内容引导语：一句具有诗意或概括性的短句，用于增强气质
5. 底部说明 / 标语 / 备注：小字收束，增强完整性
6. 如果是信息图 / 知识海报：需要加入逻辑分区、小标题、重点提炼、结构信息，但必须与整体审美统一，不能变成生硬表格

【字体与排版气质】
- 中文字体气质：宋体、明朝体、古典衬线风格、书卷气字体、细长而雅致
- 英文字体气质：细衬线、经典出版物感、不可花哨
- 主标题可采用竖排
- 辅助信息可采用左上角小字排版、右侧竖排辅助文案、底部小字收束
- 文字必须准确、整洁、留白合理，不能拥挤，不能廉价
- 整体排版要像一本高端艺术画册的封面与海报结合体
